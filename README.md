# Olymbits - Summer Challenge 2024
Each player controls an agent in four mini-games simultaneously. Earn as many medals as possible in all four games to achieve the highest score.

![Olymbits](https://github.com/user-attachments/assets/4ca7c8a9-0771-413f-bdae-d8a848e693c1)

## Deployment
To deploy this project run
```bash
git clone https://github.com/LolinEagle/codingame_summer_challenge_2024 &&
cd codingame_summer_challenge_2024 && make
```
